Odin Recipes

This is my first project as part of The Odin Project Foundations course. The goal of this project is to build a basic recipe website using only HTML.

Project Overview:

The site consists of a main index page with links to a few recipes. Each recipe has its own page that includes a description, a list of ingredients, and step-by-step cooking instructions.

Skills Demonstrated

By completing this project, I will have practiced and demonstrated the following skills:

Writing semantic HTML

Structuring a multi-page website

Using lists, links, images, and headings

Understanding relative file paths and folder structure

Following basic web development best practices
